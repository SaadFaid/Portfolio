# Saad Faid — Portfolio

A personal portfolio website for a full-stack web & mobile developer. It presents the developer's profile, work experience, highlighted projects, technical stack, and contact details in a single-page layout, with a downloadable CV and a built-in theme switcher (orange, black & white, and turquoise).

## What's included

- Profile and about section
- Work experience timeline
- Project showcase with project screenshots and links
- Technical skills grouped by area (frontend, backend, mobile, databases, tools)
- Contact section
- CV download
- Three switchable color themes
